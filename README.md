# Warning Label for Humans: One Line, Big Laugh

Entry for the make.fun bounty "Warning Label for Humans: One Line, Big Laugh".

The program writes a single-line safety warning label that should come printed on every human being to `/output/entry.txt`. The label warns about the universal human habit of saying "just one more episode" at midnight — and waking up exhausted, furious, and ready to do it all again tonight. It is written in the terse wording and rhythm of a genuine printed warning label, funny first and plausible second, in 118 characters, inside the 1–160 gate.
